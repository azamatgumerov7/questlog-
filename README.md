# Квест-лог тестировщика

Трекер ежедневных и недельных задач в игровом стиле: опыт (XP), уровни с грейдами от Trainee QA до QA Legend, серии дней, ачивки и карта прогонов за 12 недель.

Работает без Claude и без своего сервера:

- **сайт** бесплатно размещается на GitHub Pages;
- **прогресс** хранится в файле `data.json` в твоём приватном репозитории на GitHub;
- на каждом устройстве есть локальная копия, поэтому трекер работает и без интернета, а отметки отправятся в GitHub, когда связь появится.

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | само приложение |
| `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` | установка на телефон как приложение |
| `sw.js` | работа без интернета |

## Как запустить (один раз, ~10 минут)

### 1. Репозиторий для сайта (публичный)

1. Открой https://github.com/new, назови репозиторий `questlog`, выбери **Public** и нажми **Create repository**.
2. На странице репозитория нажми **uploading an existing file** (или **Add file → Upload files**), перетащи все файлы из этой папки и нажми **Commit changes**.
   Если удобнее через Git:
   ```bash
   cd questlog
   git init
   git add .
   git commit -m "Квест-лог"
   git branch -M main
   git remote add origin https://github.com/<логин>/questlog.git
   git push -u origin main
   ```
3. **Settings → Pages**: Source — **Deploy from a branch**, Branch — **main**, папка **/(root)**, нажми **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/questlog/`.

В этом репозитории только код, личных данных в нём нет.

### 2. Репозиторий для данных (приватный)

1. Снова https://github.com/new, назови `questlog-data`, выбери **Private** и поставь галочку **Add a README file** (можно и без неё).
2. Ничего загружать не нужно: трекер сам создаст `data.json`.

### 3. Токен доступа

1. Открой https://github.com/settings/personal-access-tokens/new (Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token).
2. **Token name**: `questlog`. **Expiration**: выбери срок подольше.
3. **Repository access**: **Only select repositories** → `questlog-data`.
4. **Permissions → Repository permissions → Contents**: **Read and write**.
5. Нажми **Generate token** и скопируй токен (`github_pat_…`). GitHub покажет его только один раз.

Токен даёт доступ только к репозиторию с данными. Трекер хранит его в браузере устройства и отправляет только в GitHub.

### 4. Подключение

1. Открой `https://<логин>.github.io/questlog/`.
2. Нажми на плашку **«Только это устройство»** вверху (или кнопку **«Подключить GitHub»**).
3. Впиши логин, `questlog-data` и токен, нажми **«Подключить»**.
4. На телефоне открой тот же адрес и подключи тот же репозиторий с тем же токеном.

## Установка на телефон

- **Android (Chrome):** меню ⋮ → **«Добавить на главный экран»** или **«Установить приложение»**.
- **iPhone (Safari):** кнопка «Поделиться» → **«На экран „Домой“»**.

На iPhone у установленного приложения своё хранилище, поэтому GitHub нужно подключить уже внутри него (один раз).

## Как начисляется опыт

- Каждая задача даёт свой XP (настраивается в «Задачах»).
- Все ежедневные задачи за день: **+20 XP** бонусом.
- Все недельные квесты закрыты до воскресенья: **+30 XP**.
- Недельная задача даёт XP только до своей цели (например, 2 тренировки в неделю).
- День идёт в серию, если пройдена хотя бы половина ежедневных задач.
- Учёт начинается с первой отметки: дни до неё не считаются ни в серию, ни в провалы.
- Удаление задачи: если её ни разу не отмечали, она стирается полностью. Если отмечали — можно убрать «только с сегодня» (прошлые дни не меняются) или «стереть из истории» (задачи как будто не было). Ранее удалённые задачи видны в разделе «Удалённые».
- Уровень *L → L+1* стоит `100 + 50·(L−1)` XP: 100, 150, 200…; полная таблица — кнопка **«Все уровни»**.

## Навигация

- В «Прогоне дня» стрелки ‹ › листают дни назад и вперёд (на ~3 года в обе стороны), значок календаря открывает выбор даты, на компьютере работают клавиши ← →.
- Будущие дни показывают план задач, отмечать их можно, когда день наступит. Отмечать можно сегодня и за последние 7 дней, более старые дни — только просмотр.
- Карту прогонов можно листать по 12 недель стрелками; нажатие на квадрат открывает этот день.

## Работа (Jira)

Вкладка «Работа»: задачи из Jira (In test — твои, Ready for test — свободные и твои), закрытые за день (из Jira автоматически или галочкой вручную) и свои рабочие задачи. Свои рабочие задачи добавляются в план дня, опыт за каждую выбираешь сам и получаешь, когда отметишь её галочкой. Опыт за закрытую задачу из Jira настраивается внизу вкладки (по умолчанию +20 XP). На серии и идеальные дни работа не влияет.

«Карта работы» показывает, сколько задач закрыто за день: чем больше, тем ярче квадрат. Красного нет — день без закрытых задач просто пустой, выходные заштрихованы, а если в выходной что-то закрыто, он окрашивается как обычный день.

Задачи забирает робот GitHub Actions в репозитории `questlog-data` (см. его README): каждые 15 минут в будни с 9 до 21 и по кнопке «Обновить сейчас». Для этого в `questlog-data` нужен секрет `JIRA_TOKEN` с персональным токеном Jira, а для кнопки — право **Actions: Read and write** у токена GitHub.

## Оформление

Кнопка «Стиль» вверху: «Ночная смена» (тёмно-синяя), «Полночь» (почти чёрная), «Чёрная» (OLED), «Светлый отчёт» (светлая) и «8-бит» (ретро-аркада). Выбор запоминается на каждом устройстве отдельно.

## Если что-то пошло не так

- **«GitHub не принял токен»** — у токена истёк срок или он скопирован не полностью. Создай новый и подключи заново.
- **«Нет права записи»** — у токена не выставлено Contents: Read and write.
- **«Репозиторий не найден»** — проверь логин, название и что токен выдан именно на `questlog-data`.
- **Резервная копия:** в окне синхронизации есть «Скачать копию (.json)» и «Загрузить из файла».

## Обновление

Чтобы обновить трекер, замени `index.html` в репозитории `questlog`. Данные в `questlog-data` при этом не меняются.
