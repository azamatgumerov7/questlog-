Хранить прогресс в GitHub

Прогресс лежит в файле data.json в твоём приватном репозитории. Подключи один и тот же репозиторий на ноутбуке и на телефоне, и отметки будут общими.

  1. Создай приватный репозиторий, например questlog-data: github.com/new.
  2. Создай токен: Fine-grained token → Repository access: Only select repositories → этот репозиторий → Permissions: Contents — Read and write.
  3. Впиши данные ниже и нажми «Подключить». На телефоне сделай то же самое один раз.
Токен хранится только в этом браузере и отправляется только в GitHub.
